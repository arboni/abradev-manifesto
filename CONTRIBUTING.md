# Como Assinar e Contribuir com o Manifesto ABRADEV

Agradecemos o seu apoio para fortalecer a classe de tecnologia no Brasil! Assinar o manifesto via GitHub demonstra a união técnica e orgânica da nossa categoria.

Você pode assinar de **duas formas**:

---

## Opção 1: Assinar via Pull Request (Recomendado)

1. Faça um **Fork** deste repositório (`abradev/manifesto`) clicando no botão **Fork** no topo direito da página.
2. No seu fork, abra o arquivo `ASSINATURAS.md`.
3. Clique no ícone de lápis ✏️ para editar diretamente no navegador (ou faça localmente via Git).
4. Adicione uma nova linha ao final da tabela no seguinte formato:
   ```markdown
   | N | Seu Nome / Nick | Seu Cargo / Especialidade | UF | [@seu-usuario](https://github.com/seu-usuario) |
   ```
5. Escreva uma mensagem de commit (ex: `feat: add assinatura de [Seu Nome]`).
6. Envie a alteração e clique em **Contribute > Open Pull Request**.
7. Pronto! Nossa equipe aprovará seu PR e seu nome fará parte oficial do manifesto.

---

## Opção 2: Assinar via Issue (Sem precisar editar código)

Se preferir não abrir um Pull Request:
1. Vá até a aba **[Issues](../../issues)** do repositório.
2. Clique em **New Issue** e escolha o modelo **Assinatura do Manifesto**.
3. Preencha seu Nome, Cargo/Área e Estado (UF).
4. Clique em **Submit new issue**.
5. Periodicamente as issues abertas são adicionadas à lista oficial no arquivo `ASSINATURAS.md` e fechadas.

---

## Dúvidas ou Sugestões Institucionais
Caso tenha sugestões de melhorias de redação ou propostas institucionais para a ABRADEV, sinta-se à vontade para abrir uma Issue de discussão no repositório.
